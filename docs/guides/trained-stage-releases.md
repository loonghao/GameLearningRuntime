# 将阶段训练成果交付给用户

训练到一个可用阶段后，可以发布独立版本，例如 `stage-1 / 1.0.0`。版本包含固定模型、
适配器、推理运行环境和兼容配置，默认只执行冻结推理。模型能力范围、评估结果与已知
限制必须随版本交付；能够安装不代表已经证明游戏目标完成。

完整流程见 [User releases](../../.agents/skills/glr-adapter-builder/references/user-releases.md)。
脚手架生成 `USER_RELEASE.md`，构建、运行和 QA Skills 都要求读取它。

`game_learning_runtime.user_release` 构建接口校验模型 bundle、阶段身份与逐文件
SHA-256，为准备好的自包含 Windows x64 应用生成 Inno Setup 工程，并调用明确指定
的编译器生成 EXE。安装按版本独立进行，生成快捷方式，不自动启动训练或游戏。

下游仍需先构建自己的推理启动器及运行依赖。本接口不会自动把任意训练脚本冻结成
程序，也不会提供游戏桥接、GPU 驱动或模型。签名、干净机器启动验证、真实游戏验收
和用户数据保留测试是独立发布门禁。

开发 wheel、训练复现 bundle、源码包与用户安装包各有用途。用户不应为了运行模型
而安装开发工具或取得源码。后续阶段通过新版本交付；不兼容的模型、配置或数据需要
按迁移指南试迁移并记录回滚边界。
