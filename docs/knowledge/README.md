# GLR knowledge evidence

Adapters may persist combat and route knowledge only through versioned schemas. Evidence records retain run and route identity, bounded live position, action, producer sequence, outcome, and recording metadata. Route traces are advisory replay hints; promote an edge only after repeated successful live traversals under a compatible environment and producer identity. QA distinguishes reached, skipped, blocked, combat-gated, death, and recovery outcomes.

For every boss or elite encounter, `recording_started_before_actions` must be true and attributable to the exact adapter/producer binding. A video path without that binding is not gameplay evidence. Unknown attacks remain high risk until runtime samples justify promotion into a boss-specific table.

The schema is learner-neutral: providers emit evidence, while training and QA consumers decide how to use it. Never commit workstation paths, process identifiers, credentials, or private runtime traces.
